# Seguva - **SLOGAN**
Developer: Felix Lehmann (on behalf of Seguva GmbH)
Link: **LINK**
GitHub: [SEGUVA](https://github.com/flexirexi/seguva_presence)

Frontend only landing page for the start-up SEGUVA GmbH. This repo will be handed over to this company, along with all rights to the code.

This project is a landing page of the start-up SEGUVA GmbH which shall present the company and its AI products in a modern and professional manner to the visitors. More importantly, the website offers potential clients to contact the company via a contact form. In this form, the potential client can raise requests or request more information about products and services.

In this context, the products page and the contact page remain as the main focus of this project. They must be easily accessible on desktop mode as well as in mobile mode. Since the products & services of SEGUVA GmbH are selective, very niche and specialized, potential clients already know about this product and website. It means that there is no major need to explain the products & services from the scratch. Simple graphics, key selling and short descriptions that are easy to remember are the main value driver.  

The website follows a clean and timeless design to demonstrate seriousness for SEGUVA's AI-products and services. As the products page and the contact form must be easily accessible, the whole project is styled with a mobile-first approach: by default, the design of the webpage is made for mobile screens. As soon as the screen gets bigger, additional desktop-based styled will be applied. This way unconsidered styles will have a mobile look and, hence, the website will always be visible in a professional manner.
